# Hero art (not committed)

Put your own pictures of the Shard Masters here, one per hero, named by hero id.
Any of `.jpg`, `.jpeg`, `.png` or `.webp` works:

```
public/art/decima.jpeg
public/art/kosynwu.jpg
public/art/tetra.jpg
public/art/volos.jpeg
public/art/rez.png
```

Portrait crop, roughly 3:4. When a file is missing the app shows the hero colour instead.
This folder is git-ignored on purpose: the card artwork belongs to Stone Blade Entertainment.
It is only used when running the app locally. On a phone, use the in-app "Hero photos" screen.
